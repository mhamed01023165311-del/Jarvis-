# Jarvis - Voice Assistant App

تطبيق مساعد صوتي لأندرويد للتحكم في الهاتف والتطبيقات عبر الأوامر الصوتية مع وضعين:
- **Offline Mode**: باستخدام PocketSphinx للأوامر الثابتة.
- **Online Mode**: لتفسير الأوامر المعقدة عبر نموذج AI سحابي.

## المكونات الرئيسية:
- **VoiceService**: خدمة الاستماع الصوتية في الخلفية.
- **AppAccessibilityService**: التفاعل مع واجهات التطبيقات الأخرى وحث النقر والتكست.
- **MainActivity & AddCommandActivity**: إدارة وتخصيص الأوامر الصوتية.
